# Heatmaps

**Heatmaps** (calendar heatmaps) reveal daily, weekly, and seasonal rhythms by
laying a signal out across a calendar grid and coloring each cell by value.

## When to use it

- You want to see time-of-day or day-of-week patterns at a glance.
- You're looking for recurring busy/quiet periods or shift effects.
- You want to spot days that stand out from their neighbors.

## How to use it

1. Select a signal and a range spanning enough days/weeks to reveal a pattern.
2. Read the grid — rows and columns correspond to calendar units; color encodes
   the value.

## Reading the results

- Consistent color bands across the same time-of-day or weekday reveal a rhythm.
- Isolated bright/dark cells flag unusual days worth investigating.
