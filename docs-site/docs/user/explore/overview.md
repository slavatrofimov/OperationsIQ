# Overview

The **Overview** is your starting point for looking at a signal over time. It
renders an adaptive-binned view of one or more selected signals, with optional
overlays for anomalies and events, and supports brush-to-zoom.

## When to use it

- You want to see how a signal has behaved across a period.
- You're orienting yourself before a deeper analysis.
- You want to spot obvious spikes, drops, gaps, or shifts.

## How to use it

1. Select one or more [signals](/user/getting-started/selecting-signals).
2. Choose a time range — start wide, then brush to zoom.
3. Toggle overlays (anomalies, events) if available for your data.

## Reading the results

- The chart auto-bins to keep long ranges readable; zoom in for finer detail.
- Overlaid markers flag notable points so you can jump straight to them.
- Hover for exact values; use the tooltip to compare series at a timestamp.
