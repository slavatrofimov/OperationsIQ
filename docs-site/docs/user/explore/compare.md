# Compare

**Compare** puts multiple signals side by side on aligned timelines so you can
see how they move together (or diverge).

## When to use it

- You want to visually correlate several measurements over the same period.
- You're checking whether one signal leads or lags another.
- You're building intuition before a formal relationship analysis.

## How to use it

1. Select the signals you want to compare.
2. Choose a shared time range.
3. Inspect the aligned tracks — look for co-movement, lag, and divergence.

## Reading the results

- Signals that rise and fall together may be related (or share a common driver).
- A consistent offset in time between two signals suggests a lead/lag
  relationship.
