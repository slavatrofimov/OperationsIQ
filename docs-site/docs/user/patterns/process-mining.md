# Process mining

**Process mining** discovers the **flow of events** in your operation — the
sequences and transitions between discrete states or activities — from the
underlying event data.

## When to use it

- Your data includes discrete events/states and you want to understand the actual
  process flow.
- You want to see common paths, loops, and deviations from the expected sequence.

## How to use it

1. Select the event source / scope and time range.
2. Review the discovered process map — nodes are activities/states, edges are
   transitions.

## Reading the results

- Frequent paths show how the process usually runs.
- Unexpected transitions or loops highlight deviations worth investigating.
