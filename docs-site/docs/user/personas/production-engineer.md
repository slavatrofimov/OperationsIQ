# Production engineer

You keep the process running and need to spot and diagnose issues quickly.

## A typical day

1. **Start with health.** Open [Deviations](/user/diagnose/deviations) or the
   [Diagnostic Findings](/user/diagnose/diagnostic-findings) to see what needs attention now.
2. **Confirm with SPC.** Use the [Control chart](/user/diagnose/control-chart) to
   check whether a flagged signal is statistically out of control.
3. **Diagnose.** Use [Root cause](/user/diagnose/root-cause) to trace the problem
   to likely contributors, and [Compare](/user/explore/compare) to eyeball
   related signals.
4. **Check the outlook.** [Forecast](/user/planning/forecast) a trending signal to
   see if it's heading toward a limit.
5. **Record it.** Capture the finding in an
   [Investigation](/user/investigations) for the shift handover or incident log.

## Tips

- Keep [Signal metadata](/user/diagnose/signal-metadata) limits accurate — they
  drive deviations, alerts, and control charts.
- Label recurring fault signatures so [Classifiers](/user/patterns/classifiers)
  can recognize them automatically next time.
