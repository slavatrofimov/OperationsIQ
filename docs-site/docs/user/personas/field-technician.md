# Field technician

You work close to the equipment and need focused, task-oriented answers — often
about a specific asset.

## A typical task

1. **Find the asset's signals.** Use the tag browser to locate the measurements
   for the equipment you're working on — see
   [Selecting signals](/user/getting-started/selecting-signals).
2. **Check current health.** Look at [Deviations](/user/diagnose/deviations) and
   recent [Diagnostic Findings](/user/diagnose/diagnostic-findings) for that asset.
3. **Look at the recent history.** Use [Explore → Overview](/user/explore/overview)
   to see what the signal has been doing.
4. **Validate the data.** If a reading looks wrong, check
   [Signal validation](/user/diagnose/signal-validation) to rule out a sensor
   problem before chasing a process issue.
5. **Hand off.** Add anything notable to an
   [Investigation](/user/investigations) so the next shift or an analyst can pick
   it up.

## Tips

- Trust but verify: a strange value is often a data-quality issue
  ([Signal validation](/user/diagnose/signal-validation)) rather than a real fault.
- Keep annotations short and specific — they become searchable evidence.
