# Investigations & evidence

An **Investigation** is a named case study that captures your analysis so it can
be reviewed, shared, and searched later. From (almost) any analysis page you can
**Add to investigation** to snapshot what you're looking at.

## What gets captured

When you add a page to an investigation, Operations IQ saves:

- A **Markdown snapshot** of the page's main content.
- Every **chart** as a PNG image **plus** its underlying data as **CSV**.
- Your **annotation** (your notes about why this matters).

## When to use it

- You've found something and want to preserve the evidence exactly as you saw it.
- You're building a case (incident review, root-cause writeup, audit trail).
- You want your findings organized across investigations.

## How to use it

1. While viewing any analysis, click **Add to investigation**.
2. Choose an existing investigation or create a new named one.
3. Add an annotation describing the finding.
4. Review everything later in the **Investigations** tab.

## Managing evidence

- Open an investigation to browse its captured pages, charts, data, and notes.
- Delete evidence or whole investigations you no longer need.
