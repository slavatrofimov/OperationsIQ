# Getting started

This section covers the essentials you need before diving into any module:
signing in, choosing a persona, reading the charts, and selecting the signals
(tags) you want to analyze.

## What Operations IQ does

Operations IQ sits on top of your operational time-series data (sensor tags,
process values) stored in a Fabric **Eventhouse**. It provides purpose-built
modules to:

- **Explore** — visualize signals over time with adaptive binning, overlays,
  and brush-to-zoom.
- **Diagnose** — explain relationships between signals and monitor their health.
- **Plan** — forecast future values and test what-if scenarios.
- **Discover patterns** — find recurring shapes (motifs), rare events
  (discords/anomalies), regimes, and trainable classifiers.
- **Alert** — surface deviations automatically.
- **Investigate** — capture any analysis into a shareable, searchable case study.

## The two things you'll do most

1. **Pick a time range** and **select one or more signals (tags)**. Almost every
   module starts here. See [Selecting signals](./selecting-signals).
2. **Read the resulting charts** — most modules render interactive ECharts plots
   you can zoom and brush. See [Reading charts](./reading-charts).
