# Playbooks

**Playbooks** are a guided starting point for analysis. Instead of
asking you to pick a module cold, they present expert-authored, industry-specific
**operational playbooks** — each a reusable template with a
plain-language rationale and an ordered set of steps. The **Playbooks** menu sits
between **Patterns** and **Activator Alerts**.

## What you'll see

A grid of **playbook cards**. Each card explains, in business terms, what the
playbook is for and the steps it walks through. Playbooks relevant to your
current **persona** are highlighted first.

## Filtering

Narrow the list with the filters at the top:

- **Industry** — kept in sync with the app-wide industry selector. Choose a
  specific industry, or **Cross-industry** for playbooks that apply anywhere.
- **Category** — the operational category (only categories present in the current
  view are shown).
- **Business function** — an extra sub-filter available in the Cross-industry
  view.

## Starting a playbook

Click **Start** on a card to hand its rationale and steps to the **Operations
Advisor** (the in-app assistant), which then guides you through the analysis
conversationally. (Starting a playbook requires the Operations Advisor to be
configured; if it isn't, the cards are still browsable for reference.)
