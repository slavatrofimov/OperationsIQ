# What-if (scenarios)

**What-if** lets you test hypothetical conditions — change one or more driver
signals and see how a target is expected to respond.

## When to use it

- "What happens to output if we raise this input by 10%?"
- You want to compare scenarios before making an operational change.
- You're stress-testing a plan against different assumptions.

## How to use it

1. Choose the target signal you want to project.
2. Set hypothetical values or adjustments for the driver signals.
3. Review the resulting projected behavior of the target.

## Reading the results

- Compare scenarios side by side to see which assumptions matter most.
- Scenario results are only as good as the underlying relationship model — see
  [Regression & sensitivity](/user/diagnose/regression-sensitivity).
