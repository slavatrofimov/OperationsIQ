# Influence map

The **Influence map** shows relationships between signals as a network, helping
you see which measurements tend to influence which — a starting point for
understanding how your process is wired together.

## When to use it

- You want a big-picture view of how signals relate.
- You're looking for unexpected couplings between parts of the process.
- You want to narrow down candidates before a formal root-cause analysis.

## How to use it

1. Select the signals (or an asset scope) to include.
2. Choose a time range representative of the behavior you care about.
3. Explore the resulting network — nodes are signals, links indicate influence.

## Reading the results

- Strongly linked signals move together or one appears to drive the other.
- Hubs (highly connected nodes) are often key process variables.
