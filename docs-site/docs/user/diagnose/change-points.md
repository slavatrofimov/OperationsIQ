# Change points

**Change points** detects *when* a signal's behavior shifts — a change in mean,
variability, or regime — and marks those moments on the timeline.

## When to use it

- You want to know exactly when something changed.
- You're correlating a behavior shift with a maintenance event or process change.
- You want to segment a signal into before/after periods.

## How to use it

1. Select a signal and time range.
2. Review the detected change points marked on the chart.

## Reading the results

- Each marked point indicates a statistically significant shift.
- Compare the segments on either side to characterize what changed (level,
  volatility, cycle).
