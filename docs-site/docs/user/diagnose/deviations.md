# Deviations

**Deviations** highlights where signals depart from their expected behavior,
giving you a health-at-a-glance view across your monitored measurements.

## When to use it

- You want a quick read on which signals are currently misbehaving.
- You're triaging where to focus during a shift.

## How to use it

1. Select the signals or asset scope to monitor.
2. Review flagged deviations, ranked or highlighted by severity.

## Reading the results

- Flagged periods indicate departures from expected ranges or patterns.
- Use governed [signal metadata](./signal-metadata) limits to make "expected"
  meaningful for each tag.

## Related
