# Root cause

**Root cause** helps you trace a problem — an excursion, alarm, or anomaly —
back to the signals most likely contributing to it.

## When to use it

- Something went wrong and you need to find *why*.
- You have a target signal that misbehaved and want ranked candidate causes.

## How to use it

1. Identify the target signal and the time window of the problem.
2. Provide candidate signals (or a scope) to evaluate as potential causes.
3. Review the ranked contributors and their supporting evidence.

## Reading the results

- Candidates are ranked by how strongly they relate to the problem window.
- Use the evidence (aligned charts, statistics) to confirm plausibility — a
  statistical link is a lead, not proof.
